\section{Introduction}
This report describes the implementation of a Deep Neural Network (DNN) microserver
for handwritten digit recognition (MNIST) running on the Zybo Z7 platform.
The application performs real-time inference on images streamed via UART and
is designed according to embedded system constraints.

\section{Target Platform and Development Environment}
The application targets the Processing System (PS) of the Zynq-7000 SoC,
specifically the ARM Cortex-A9 core available on the Zybo Z7 board.
The software is developed as a standalone application using the Xilinx SDK.

\section{Fixed-Point DNN Implementation}
The DNN inference is implemented entirely using fixed-point arithmetic.
All weights, biases, and activations are represented as 16-bit integers
using a Q-format representation.

\section{UART-Based DNN Microserver}
\subsection{Input Streaming}
MNIST images are streamed from a host PC to the board via UART as raw pixel values.
Each image consists of 784 samples.

Additional optimizations were explored by modifying input and weight representations,

\section{Conclusions}
This work demonstrates that a fully software-based DNN can achieve real-time
MNIST classification on an embedded ARM Cortex-A9 platform when fixed-point
arithmetic and careful system design are employed.
