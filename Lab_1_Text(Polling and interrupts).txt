Polling and interrupts
Istruzioni
This assignment is related to Lab 1 on polling and interrupts. Please refer to workspace and code used in Lab. 
Please prepare the following code versions:

a) polling basic version, checking switches. Please show on LEDs the same pattern indicated by the switches.

b) an interrupt version (part 1) - two interrupt sources with an AXI Interrupt Controller. (Constraint: Use at least one or- or and- masks.) Interrupt service routines:
Switch interrupt (SW): On a switch change, read the 4 input switches and show on the LEDs the binary index of the most-significant switch that is ON (3..0). If no switches are ON, show 0x00.
Button interrupt (BTN): On a button press or release, negate (invert) the current LED pattern.
 ----Example Cycle snapshot:
     ----Switch = 0b0101  → MSB=2 → Led = 0010
     ----Button pressed       → invert → 1101
     ----LEDs final = 1101

c) an interrupt version (part 2) Change the button interrupt (BTN): On a button press, add the last digit of your student ID to the current LED pattern and negate.
